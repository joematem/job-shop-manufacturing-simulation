# Model assumptions

This file will document assumptions used in the Job Shop simulation.

Do not populate assumptions by guesswork.

When the actual model is reviewed, record items such as:

- arrival process;
- job/product mix;
- processing-time distributions;
- resource capacity;
- queue/buffer capacity;
- routing rules;
- working hours;
- transport speed;
- breakdown/repair assumptions;
- storage assumptions;
- simulation horizon;
- warm-up period;
- replication count.

For each assumption, state whether it comes from:

1. tutorial/model specification;
2. measured/real data;
3. literature;
4. modelling simplification;
5. analyst judgement.

This makes the portfolio more credible and reproducible.
