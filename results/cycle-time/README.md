# Cycle-time results

This folder will store actual end-to-end job/product cycle-time results.

Suggested definition:

```text
cycle time = completion time - system entry time
```

Possible measures:

- mean;
- median if externally analysed;
- minimum;
- maximum;
- standard deviation;
- distribution/histogram;
- cycle time by product/job type if applicable.

Recommended files:

```text
cycle-times.csv
cycle-time-histogram.png
cycle-time-summary.md
```
