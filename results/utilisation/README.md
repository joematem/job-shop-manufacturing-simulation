# Utilisation results

This folder will store measured utilisation for the resources actually present in the model.

Potential resources include:

- processing machines;
- CNC machines if present;
- operators;
- forklifts;
- transporters;
- loaders;
- other resource pools.

Recommended outputs:

```text
resource-utilisation.csv
utilisation-comparison.png
utilisation-summary.md
```

Only resources confirmed in the actual Job Shop model should be reported.
