# Portfolio images

This folder is reserved for screenshots from the actual Job Shop model.

## Please provide these images

### 1. `model-overview.png`
A full screenshot of the AnyLogic model showing the main process blocks and connections.

### 2. `3d-factory.png`
A runtime screenshot of the full manufacturing environment if the model uses 3D animation.

### 3. `process-flow.png`
A close screenshot showing the production sequence, routing, queues and major process blocks.

### 4. `resource-area.png`
A close screenshot showing the important machines, resources, forklifts, transporters or material-handling area actually used in the model.

### 5. `dashboard.png`
A screenshot of the final KPI dashboard after the analytical visualisations are implemented.

### 6. Optional scenario images
Screenshots that make scenario differences visually clear.

Use only screenshots from the actual working model. Do not use invented results.
